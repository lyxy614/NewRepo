# 跳蛛大战游戏（更新日志）
## V1.0.0

该项目是一个非常简单的控制台程序。这是该项目的第一个版本。

玩家可以选择自己的跳蛛，使用进攻、防御以及其他技能来与敌对跳蛛进行回合制战斗。

目前只有两种跳蛛供玩家选择，以后可能会拓展更多跳蛛和专属技能，或进行玩法的改动。

创建该项目的用意是巩固我的Java面向对象编程能力和git使用能力。
